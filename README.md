drawn deterministically with Python + Pillow. Entry for the make.fun
[news-image-20261125](https://make.fun/bounty/news-image-20261125) bounty.

## Run it

```sh
python3 main.py            # writes /output/entry.png
python3 main.py out.png    # or any path, for a local test
```

The program is deterministic: two runs produce byte-identical output.
Output: one 768×1024 PNG, about 103 KB.
